# VibeTalk

**VibeTalk** — веб-приложение для общения в формате мессенджера, вдохновлённое Discord.

Платформа позволяет находить друзей, обмениваться сообщениями в реальном времени, отправлять изображения и файлы различных форматов, а также совершать личные голосовые и видеозвонки.

Кроме того, в VibeTalk предусмотрена система тематических серверов по интересам и задачам, где пользователи могут публиковать посты, объединяться в сообщества и проводить групповые звонки.

## Деплой на VPS

GitHub Actions проверяет pull request и push в `main` на Python 3.12 с временными PostgreSQL 14 и Redis 7. После успешных проверок push в `main` запускает выкладку по SSH от пользователя `django`. Workflow использует секреты `SERVER_HOST` и `SERVER_SSH_KEY`. Публичный SSH-ключ хоста закреплён в workflow. При замене VPS или ротации ключа сверьте новый ключ через консоль сервера и обновите его в workflow.

На VPS приложение находится в `/home/django/vibetalk`. Путь `venv` ведёт в `/opt/python-jammy/venvs/vibetalk`. Django использует локальный PostgreSQL и внешний Redis из `REDIS_URL`. Nginx завершает TLS, отдаёт `/static/` из `website/static/` и `/media/` из `website/media/`. HTTP и WebSocket под `/ws/` он направляет на Daphne по адресу `127.0.0.1:8001`.

Скрипт выкладки обновляет код до проверенного коммита, устанавливает зависимости, применяет миграции, собирает статику и перезапускает `vibetalk-daphne.service`. Затем он ждёт HTTP 200 от Daphne на `/login/`, а GitHub Actions проверяет страницу входа и CSS через публичный HTTPS. Выкладка выполняется в рабочем каталоге сервера. При ошибке после миграций или перезапуска workflow сообщает о сбое. Откат приложения и базы выполняется вручную.
